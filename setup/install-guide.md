# Installing Obsidian

## Step 1: Download Obsidian

Go to [obsidian.md](https://obsidian.md) and click the download button for your computer (Mac, Windows, or Linux). It's free for personal use.

Install it like any other app — drag to Applications on Mac, or run the installer on Windows.

## Step 2: Open Your Vault

When you first open Obsidian, it will ask you to create or open a vault. A "vault" is just a fancy word for a folder of notes.

1. Click **"Open folder as vault"**
2. Navigate to the `second-brain-starter-kit` folder you downloaded
3. Select it and click Open

You should see the folder structure on the left: Inbox, Notes, Daily, Projects, Archive, Templates.

## Step 3: Trust the Plugins

Obsidian might show a warning about community plugins. This starter kit includes three pre-configured plugins:

- **Calendar** — Shows a calendar in the sidebar for navigating daily notes
- **Dataview** — Lets you query your notes (Claude Code uses this)
- **Templater** — Powers the note templates

Click **"Trust author and enable plugins"** (or go to Settings > Community Plugins > Turn on community plugins, then enable each one).

## Step 4: Check the Graph

Click the graph icon in the left sidebar (it looks like a network of connected dots). This is your knowledge graph. Right now it's empty — but it won't be for long.

## Step 5: You're Done

Go back to Claude Code and say `/import` to bring in your existing notes, or just start dropping files into the `Inbox` folder and say `/process` when you're ready.
